# 004 Zora で Cloudflare にホスティングする静的サイトの構築

作成日時: 2025-08-21 12:00

## 概要

### 要件

- **Zora を使用して Cloudflare にホスティングする静的サイトの構築**

  - 登録された複数のリポジトリ内の `.doc/scrap` ディレクトリにある Markdown ファイルを収集し、静的サイトとしてパース。
  - 静的サイトを Zora を介して Cloudflare にホスティング。

- **リポジトリの更新検知と自動更新**

  - 登録されたリポジトリが更新された場合、静的サイトを自動的に再生成してデプロイ。

### 実装計画

1. **リポジトリの登録と管理**

   - `repositories.json` を用意し、対象リポジトリを管理。
   - 各リポジトリの `.doc/scrap` ディレクトリ内の Markdown ファイルを取得。

2. **Markdown ファイルの収集とパース**

   - GitHub API を使用してリポジトリの内容を取得。
   - Markdown を HTML に変換し、目次やナビゲーションを自動生成。

3. **静的サイトの生成**

   - Zora を使用して HTML を静的サイトとして構築。

4. **Cloudflare へのデプロイ**

   - Zora のデプロイ機能を使用して Cloudflare Pages にデプロイ。

5. **更新検知の実装**

   - GitHub Webhook を設定し、リポジトリの更新を検知。
   - 更新が検知された場合、静的サイトを再生成して再デプロイ。

### 使用技術

- **バックエンド**: Node.js または Python
- **静的サイト生成**: Zora
- **デプロイ**: Cloudflare Pages
- **リポジトリ操作**: GitHub API
- **更新検知**: GitHub Webhook
