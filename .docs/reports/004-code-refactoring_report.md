### 技術的な実装詳細

#### デバッグ機能の仕様

```rust
pub struct DebugConfig {
    pub vault_path: PathBuf,  // 固定: "./debug-vault"
    pub enabled: bool,        // デバッグモードの有効/無効
}
```

主要メソッド:

- `new()` - デバッグ設定作成
- `ensure_debug_vault()` - ディレクトリ自動作成
- `generate_dummy_data()` - サンプルデータ生成
- `debug_log()` - デバッグログ出力

#### インポート修正の詳細

修正前:

```rust
// src/mcp/tools/mod.rs
pub use save_markdown::*;

// src/vault/mod.rs
pub use operations::*;

// テスト内
use super::*;
```

修正後:

```rust
// src/mcp/tools/mod.rs
pub use save_markdown::{execute_save_markdown_file, TARGET_DIRECTORY};

// src/vault/mod.rs
pub use operations::VaultOperations;

// テスト内
use super::{execute_save_markdown_file};
use crate::vault::VaultOperations;
use anyhow::Result;
```
