# 004\_メモ転送ツールの実装.md

作成日時: 2025-08-14:15:51

## 概要

- Copilot でプロジェクト下の markdown ファイルを Obsidian のテンプレートに従って編集し指定の Vault のディレクトリに保存したい
- Vault はプロジェクト下ではないので本プロジェクトの MCP サーバーを経由してファイルの転送を行う
- テンプレートを取得するツール、タグの候補を取得するツール、Vault に保存するツールを実装する

## 仕様

下記手順で Copilot の処理を行うことを考えている

1. プロジェクト下の markdown ファイルをコンテキストとして Copilot の処理を開始
2. MCP サーバー からテンプレートを入手（実装するツール 1）
3. MCP サーバー からタグの候補リストを入手（実装するツール 2）
4. テンプレートの作成日など入力事項を記述
5. 入力した markdown ファイルの内容に近いタグをタグ候補リストから選定、テンプレートに記入
6. プロンプトにしたがいファイル名を決定
7. 作成した markdown を MCP サーバーに転送して Obsidian の Vault に保存(execute_save_markdown_file ツール)

プロンプトの案もプランファイルに提示してほしい

### 実装するツール 1

- MCP サーバーから markdown ファイルを転送する
- 転送するファイル(template_file)は Config にて設定
- `valut_path.join(template_file)`でパスを得る
- template_file の型は Option<PathBuf>としてデフォルト（config で設定されてない場合）は None
- None の場合、テンプレートがないことを MCP が通知する

### 実装するツール 2

- MCP サーバーからタグのリストを転送する
- 転送するタグのリスト(tag_list)は Config にて設定
- tag_list の型は Vec<String>でデフォルトはデフォルト（config で設定されてない場合）は "Tips"のみとする
