# 003\_デバッグモードの拡張.md

作成日時: 2025-08-13:10:27

## 概要

- デバッグモードで起動したときの挙動を拡張する
- 設定ファイルの読み込み先をデバッグモードでは変更する

## 仕様

- 現行の設定ファイルの読み込みは`src\config.rs`に記述されている

```rust
    /// 設定ファイルのデフォルトパスを取得
    pub fn default_config_path() -> PathBuf {
        if let Some(config_dir) = dirs::config_dir() {
            config_dir
                .join("obsidian-mcp-server")
                .join("config.toml")
        } else {
            PathBuf::from("config.toml")
        }
    }
```

- デバッグモードで起動時には`PathBuf::from(".config/config.toml")`の設定を読み取りたい
- `PathBuf::from(".config/config.toml")`は`src\debug.rs`の`DebugConfig`構造体に記述する
- `src\main.rs`でデバッグモードの`Config`構造体生成時にパスを渡す形に実装する
