# 005\_プロジェクト構造の変更.md

作成日時: 2025-08-16:15:30

## 概要

- 現行のプロジェクトでは MCP プロトコルの実装を自力で行っている
- プロトコルの理解が浅く、実装の可否が分からないので rmcp クレートを使った実装にする

## 仕様

- MCP プロトコルは[modelcontextprotocol/rust-sdk: The official Rust SDK for the Model Context Protocol](https://github.com/modelcontextprotocol/rust-sdk)を使い実装する
