# 005-03 Rust SDK 移行最終化 (クリーンアップ / 旧実装削除)

作成日時: 2025-08-16 15:50
参照アイディアファイル: `005_プロジェクト構造の変更.md`
依存コーディング計画: `005-01-migrate-to-rust-sdk-setup.md`, `005-02-migrate-to-rust-sdk-core.md`

## 目的

SDK ベース実装へ完全移行し、不要となった旧 MCP 実装 (`protocol.rs`, `server.rs` など) を削除・置換。仕様書とドキュメントを更新し、安定運用フェーズへ移行する。

## スコープ

- 旧 JSON-RPC / MCP 手書き構造体・サーバー削除
- 新 SDK 実装へ main ルート統一 (環境変数フラグ撤廃)
- 互換性層 (型エイリアス等) の整理/最小化
- 仕様書 (`project.md`) 更新: プロトコル層再記述
- レポート作成 (差分概要)
- テストの命名/内容更新 (Legacy -> Sdk)

## 非スコープ

- 新ツール追加
- 高度な機能 (streaming / cancellation) 実装

## 移行判定基準

| 項目         | 基準                                          |
| ------------ | --------------------------------------------- |
| 全ツール動作 | 3 ツールが SDK 経由で正常応答                 |
| ログ         | 旧実装との差異なし (レベル/出力先)            |
| エラー       | 代表的異常ケースが期待メッセージ/コードで返却 |
| テスト       | 全緑 (旧テスト改名含む)                       |
| ビルド       | 警告最小 (allow(dead_code) 除去)              |

## 詳細仕様

### 削除対象 (想定)

| ファイル              | 代替                        |
| --------------------- | --------------------------- |
| `src/mcp/protocol.rs` | SDK 型                      |
| `src/mcp/server.rs`   | `src/mcp/sdk_server/mod.rs` |
| 旧エラー型 `McpError` | SDK エラー (変換)           |

### 残存/抽出対象

- `VaultOperations` / `Config` / 各ツール本体ロジック → SDK 非依存のコア層として維持

### main.rs 更新

- フラグ分岐削除
- SdkMcpServer 起動のみ

### ドキュメント更新点

- "MCP Protocol" セクション: 手書き構造体説明を SDK 利用説明へ改稿
- 新アーキテクチャ図
- 旧実装差分 (簡潔) を "変更履歴" に追記

## 実装手順

1. フラグ分岐削除 + SdkMcpServer 直起動
2. 未使用 Legacy 型除去 / ファイル削除
3. コンパイル/テスト修正
4. 仕様書 (`project.md`) 更新
5. レポート作成

## テスト計画

- 回帰: 3 ツール + 初期化
- エッジ: テンプレ未設定 / 不正ファイル名 / vault 外アクセス
- 依存削除後の dead_code 検出 (cargo clippy / warnings) — 可能なら抑制

## リスクと対策

| リスク                     | 対策                                  |
| -------------------------- | ------------------------------------- |
| 削除による想定外参照崩壊   | 段階的削除: コンパイルエラー都度修正  |
| SDK 仕様差異による挙動変更 | テストケースで期待値固定              |
| エラーメッセージ変更       | メッセージ正規表現/部分一致比較で安定 |

## 完了条件

- 旧ファイルがリポジトリから削除されている
- 仕様書更新済み (更新日時反映)
